# 小说本地化工作台

这是一个只在 Windows 本机运行的桌面程序，不再使用浏览器界面。

## 启动

双击：

```text
启动小说本地化工作台.bat
```

首次启动会在项目内创建 `.venv` 并安装 PySide6 桌面组件；以后启动会直接打开
独立窗口。关闭窗口即可退出程序。

## 当前功能

### 01 项目导入

- 新建小说项目，或把后续 TXT 章节加入已有项目。
- 支持一次导入多个拆分章节。
- 章节按内容校验，重复内容不会再次导入。
- 可附加本项目专用的 Markdown、TXT、JSON 或 YAML 规则 / Skill。
- 已有项目无需再次导入 TXT，也可以单独追加 Skill；已有 Skill 支持单个编辑和多选删除。
- 更换 Skill 后，可在“翻译处理”页重新选择已导入章节生成新译文；新结果会覆盖该章节的旧译文与处理记录。
- 可设置人名、地名、人物称呼、医院名、食物名等任意替换类别。
- 每个项目可独立设置“专名本地化/改名”。新项目与旧项目默认开启；关闭后不会强制改写人名、地名等专名，也不会套用历史强制改名映射。
- 已有项目可直接点击“保存项目设置”修改该开关，不必重新导入章节或 Skill。关闭开关不会删除现有替换清单，重新开启后仍可继续使用。

### 02 API 与 Key

- 支持保存多套 API 和模型配置。
- 支持 OpenAI Responses API、Anthropic Messages API、
  Google Gemini Interactions API 和 OpenAI 兼容接口。
- API Key 使用 Windows DPAPI 绑定当前 Windows 用户加密保存。
- 可以在界面中实际测试连接；测试可能产生少量 API 费用。

### 03 翻译处理

- 选择项目、API 配置和一个或多个章节开始翻译。
- “保存项目配置”会为当前项目保存所选 API 配置、最大输出 Token，以及用户选择保存的额外要求。项目只记录 API 配置 ID；API Key 仍只存在全局加密配置库中。
- API、Token 和额外要求只有点击“保存项目配置”才会持久化；切换项目或重启后会恢复该项目自己的设置，不会继承其他项目的临时选择。
- 章节队列支持勾选后批量删除；删除前会二次确认，并清理对应原文、译文和处理记录。
- 高亮任意章节后可打开“查看替换清单”，按类别查看该章使用的人名、地名及其他替换。
- 章节/预览区与日志区之间可拖动调节高度，翻译页右侧提供整体纵向滚动。
- 执行前明确选择“翻译”或“润色”；原文语言和目标语言决定语言转换方向。
- 首次处理新导入或修改过的 Skill 时，会使用当前 API 解析一次其替换与改写规则；内容未变化的 Skill 会复用本地缓存，不重复消耗 API。
- 点击“开始处理”即可；不再单独扫描整章或要求人工确认设定。
- 开启“专名本地化/改名”时，模型在处理正文的同一次请求中自动识别人名、地名等并生成新名称，避免重复发送整章正文，节省 Token。
- 每个导入 TXT 都按一篇独立小说处理。每次翻译时自动附加：
  - 项目规则 / Skill；
  - 当前这篇小说已经确认的人名、家族名和人物称呼；
  - 用户为本批次填写的额外要求。
- 中文小说日语本地化会附加受限的上一分段原文、译文和章节衔接信息。
- 日语原文改名润色在自然分段时不重复发送上一段；仅在超长文本被迫硬切时附加最小原文接缝。
- 开启专名改名时，两种模式都会附加当前小说的强制改名清单和同章前段新产生的临时名称；关闭时则绕过这些映射。
- 模型必须返回完整译文和本章新出现的替换项。
- 同一章的前段产生的新名称会作为临时记忆传给后续分段；整章成功后保存到该章自己的替换清单，不会传给下一篇小说。
- 长章节每完成一个分段会在本地保存检查点。截断响应会细分当前段并保留已产生的用量；下次重新处理失败章节时会从失败分段续跑，不会重复发送此前成功的分段。
- 同一人物在本章内一旦已有目标名，不允许模型自动生成第二个名字；不同小说可以重复使用相同的目标名。
- 人名、地名等强制改名类别不允许保存“原词和新名称相同”的映射；历史同名错误映射会被忽略。
- 原文中不存在的替换项不会写入。
- Skill 要求删除的作者后记、宣传、新作预告和插画说明可以作为空分段跳过，不会让已有正文翻译失败。
- 少数路人名未替换时，章节仍会正常完成；程序不再为此自动全文重做或删除章节。
- 每章仅保留最新的译文和处理记录；重新处理成功后会覆盖旧文件。
- 章节失败不会阻止后续章节继续处理，可以取消批次。

## 数据位置

```text
data/
├─ config/
│  └─ api_profiles.json          # API 配置；Key 为 Windows 加密内容
└─ projects/<项目编号>/
   ├─ project.json               # 项目、章节和翻译记录
   ├─ source/                    # 原文 TXT
   ├─ skills/                    # 项目规则 / Skill
   ├─ replacements/              # 旧版或用户手工维护的全局替换清单
   ├─ memory/project_memory.json # 已确认人物设定、关系和章节衔接记忆
   └─ output/                    # 译文及每次翻译的元数据
```

`data` 不会加入 Git。请像备份小说原稿一样定期备份这个文件夹。

## 隐私和费用

项目资料平时只保存在本机。只有用户在“测试连接”或“开始翻译”的确认框中选择继续后，
程序才会把相应测试消息或所选章节、项目规则和替换清单发送给指定 API 服务商。
外部 API 可能收费，具体费用和数据处理方式以服务商规则为准。
